## 便宜套餐里的“原生IP”，先分清真伪

原生IP指IP注册地与服务器实际所在地一致：WHOIS、地理位置库和实际路由都指向同一个地区。很多便宜套餐宣传的“原生IP”，其实是广播IP——IP段在A国注册，却从B国机房通过BGP广播出来。基础查询看地区没问题，但流媒体平台、支付通道会深查ASN、注册国和路由路径，广播IP过不了深查，往往几小时内就被标记。

这一步可以自己验证。拿到IP后用Scamalytics、IPQualityScore或MXToolbox查欺诈值和黑名单记录，几秒钟的事。第三方实测里，丽萨主机台湾ISP住宅IP的Scamalytics欺诈值为0，属于干净段。同样叫“便宜台湾VPS”，有的解锁一切，有的连动画疯都打不开，差的就是这个。
